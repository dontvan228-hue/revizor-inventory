# Ревизор — инвентаризация с телефона

Приложение, которое ставится на телефон прямо из браузера (PWA) и работает без интернета.
Цель — посчитать склад или магазин за час.

## Что умеет

- **Сканер штрихкодов и QR** камерой телефона; каждый пик = +1, кнопки +5/+10, ввод итога, голосовой ввод числа. Работает и с Bluetooth-сканером.
- **Распознавание товара по фото**: штрихкод на снимке → сравнение с фото каталога (нейросеть на телефоне) → чтение текста этикетки (OCR) → по желанию ИИ Claude (свой API-ключ).
- **Минусовые остатки**: показывает товары, ушедшие в минус по учёту, и похожие на них товары — их считают первыми.
- **Пересорт**: в отчёте автоматически подбирает пары «недостача ↔ излишек» похожих товаров и считает реальную недостачу после зачёта.
- **Saby (СБИС)**: импорт каталога с остатками, выгруженного из Saby (код, артикул, несколько штрихкодов), и «Файл для Saby» — результат для загрузки в документ «Инвентаризация» (Склад/Документы → + → Инвентаризация → скрепка → Разобрать, разбор со 2-й строки). Инструкция внутри: «Ещё → Как работать с Saby».
- **Каталог Saby без штрихкодов** (Наименование / Цена / Остаток): строки-разделы становятся категориями, пустой остаток = 0. Штрихкод привязывается при первом скане (поиск по словам: «lost mary мята»), дальше пик считает сразу.
- **Дубли карточек**: одинаковые названия в разных разделах Saby складываются, показываются отдельным списком и листом в отчёте — основная причина минусов.
- **Импорт** остатков из Excel/CSV (выгрузка из 1С, МойСклад и т.п.) — колонки распознаются по названиям.
- **Отчёт в Excel**: сличительная ведомость, расхождения, пересорт, минусы, неизвестные коды, журнал действий.
- **Зоны** (стеллажи, комнаты), прогресс, скорость и прогноз времени.
- **Несколько телефонов**: каждый считает свою зону, затем «Объединить подсчёт».
- **Файлы**: хранение накладных, фото, PDF, Excel на телефоне; скачать / отправить.
- **Этикетки с QR** для товаров без штрихкода, печать в PDF.
- Резервная копия и восстановление, светлая/тёмная тема.

## Установка на телефон

Откройте ссылку на приложение:
- **Android (Chrome)** — меню ⋮ → «Установить приложение».
- **iPhone (Safari)** — «Поделиться» → «На экран Домой».

Все данные хранятся только на телефоне. Делайте резервные копии (Ещё → Сохранить копию).
